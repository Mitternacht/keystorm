Privacy

Your voice stays on your Mac.

Keystorm is built so that dictation works without sending your audio or text anywhere. This page describes the app as it is today, while it is still in development.

What Keystorm sends

Nothing while you dictate. Speech recognition and text cleanup run on your Mac. There is no account, no cloud service, no analytics and no crash-reporting service.

The only network use is downloading the speech and text models, and only when you choose to install them. They come from Hugging Face, and every file is checked against a checksum pinned in the app. Like any download, Hugging Face can see the request.

What Keystorm stores

  • Recordings, transcripts and versions are saved in ~/Library/Application Support/Keystorm on this Mac, so a crash or restart doesn’t lose them. The downloaded models live there too.
  • Learned words are stored on this Mac only if you turn learning on, and each one needs your approval before it is used.
  • Settings such as shortcuts and blocked apps are stored in the app’s preferences.

You can export recordings as files. Moving a recording to Keystorm’s Trash can be undone; to delete everything for good, quit Keystorm and delete the folder above.

Permissions

  • Microphone is used only while you record.
  • Accessibility lets Keystorm find the text field you started in and put the result there. In TextEdit it also confirms that the text arrived. Without this permission, dictation still works and the text stays in Keystorm for you to copy.

What Keystorm reads

  • Blocked websites. If you block a website, Keystorm reads the address of the page you are typing in when you start and again before pasting. It compares the address on your Mac and never saves it.
  • Context. An optional setting, off by default, can give the local model nearby text to improve cleanup. That text is not saved.
  • Clipboard. When Keystorm pastes into an app, it places the text on the clipboard for a moment and restores what you had there whenever it can.

Password fields are always excluded, and so are these password managers: 1Password, Apple Passwords, Keychain Access, Bitwarden, KeePassXC, LastPass, Dashlane, Enpass and Proton Pass. Keystorm reads nothing from them and pastes nothing into them. You can block any other app in Settings.
